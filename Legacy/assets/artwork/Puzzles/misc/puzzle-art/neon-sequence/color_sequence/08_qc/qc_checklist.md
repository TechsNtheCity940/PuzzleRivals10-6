# QC Checklist

- No words, numbers, logos, or watermarks present.
- All exported assets retain transparent backgrounds.
- All animated strips use 256x256 frame boxes and 8 frames per loop.
- Button pulse sheets were sliced directly from the approved source strip.
- Orb glow sheets preserve centered composition and stable scale across frames, with `soft` recommended for normal gameplay and `full` reserved for emphasis.
- Board slot extractions removed the flat dark backdrop; review center slot first if a softer edge is desired.
- Phaser helper keys match filenames and animation names deterministically.
