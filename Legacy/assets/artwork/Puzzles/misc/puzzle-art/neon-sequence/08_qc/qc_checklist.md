# QC Checklist

- Transparent backgrounds verified on every exported sprite sheet.
- No words, letters, numbers, logos, or watermarks present.
- All animated strips are one-row layouts with clean frame boundaries.
- Board sheet frame order verified as 4x4, 6x6, 8x8.
- Light tile frame order verified as cyan, magenta, lime, amber, violet, coral.
- FX overlays remain centered and aligned to 256x256 tile space.
- UI icon sheet remains readable at 128x128 and smaller HUD scales.
- Color separation remains legible for fast playback and player recall.
- No perspective drift between sheets; all assets remain top-down orthographic.
- Phaser metadata keys match saved filenames and frame dimensions.
