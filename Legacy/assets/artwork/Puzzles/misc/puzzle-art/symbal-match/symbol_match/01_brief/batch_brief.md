# Batch Brief

Project slug: memory_lights
Mode slug: symbol_match

Assumptions:
- Camera is orthographic top-down because this is a board memory puzzle.
- Phaser target uses fixed 256x256 frames for all animated assets.
- Symbol reveals are one-shot during the memorize window.
- Tile backs use the source shimmer loop as the gameplay default and a brighter focus loop for hover or selected states.
- Assets are text-free and exported with transparent backgrounds for direct Phaser use.
