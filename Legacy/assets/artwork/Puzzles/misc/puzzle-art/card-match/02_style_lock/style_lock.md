# Style Lock

- Art style: glossy arcade card icons with metal frame borders
- Materials: painted icon face, metallic card frame, bright emissive accents
- Palette: one dark card back plus 24 distinct face colors and icons
- Lighting: fixed top-lit card render with stable highlights
- Silhouette: portrait card rectangle only, centered in frame
- Readability: icon-first, no text in delivered game assets
- Mood: time-pressure puzzle memory board
- Composition: one centered card per transparent frame
- Camera: frontal card presentation
- Rendering: clean production sprite sheets, no words, no logos, no watermarks
