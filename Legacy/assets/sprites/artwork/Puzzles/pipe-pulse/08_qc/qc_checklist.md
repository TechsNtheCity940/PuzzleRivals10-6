# QC Checklist

- No accidental text, logos, or watermarks
- Top-down camera remains consistent across the set
- Pipe connection points remain readable at board scale
- Transparent backgrounds preserved
- Animation strips keep exact frame counts
- Neon palette remains coherent across board, pieces, and FX
- Broken pieces read as hazards, not alternate objectives
- Burst animation reads clearly as a one-shot failure event
- Review animation strip slicing before direct engine import because generated widths may not divide evenly by frame count
