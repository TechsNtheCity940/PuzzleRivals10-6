# Style Lock

Master style prompt:
Clean top-down symbol tiles for a memory puzzle, luminous sci-fi trim, centered composition, steady rim lighting, crisp silhouettes at small scale, transparent background, no text.

Global negative prompt:
words, letters, numerals, logo, watermark, cropped frame, merged frames, scenery, perspective tilt, muddy glow, motion blur.

Sprite-sheet wrapper prompt:
exact horizontal strip, 6 frames, 256x256 per frame, transparent background, stable scale, stable lighting, centered tile, even spacing.

Animation-strip wrapper prompt:
reveal pulse or shimmer loop, no extra VFX outside frame bounds, no framing labels, no opaque shadows.
