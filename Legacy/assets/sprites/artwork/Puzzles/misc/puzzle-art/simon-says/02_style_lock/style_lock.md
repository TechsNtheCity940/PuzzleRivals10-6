# Style Lock

- Art style: clean sci-fi puzzle tile render with luminous diamond motifs
- Materials: dark glass/metal base with soft emissive neon edge bloom
- Palette: cyan, purple, green, gold, red families with cool gray line work
- Lighting: centered emissive pulse with stable outer bloom
- Silhouette: diamond tile only, centered, no perspective drift
- Readability: strong inner glyph contrast, visible at small board scale
- Mood: polished arcade memory puzzle feedback
- Composition: one centered tile per frame on transparent background
- Camera: orthographic top-down
- Rendering: transparent-background production sprite sheet, no text, no UI labels
